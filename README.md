# 🧪 Periodic Table — Interactive Chemical Elements Table

## តារាងខួបនៃធាតុគីមី — តារាងអន្តរកម្ម

## 📖 Description / ព័ត៌មានលម្អិត

### English

An interactive, bilingual periodic table web application featuring all 118 chemical elements with support for both English and Khmer languages. This educational tool is designed for students and chemistry enthusiasts, providing a beautiful, responsive interface with smooth animations and comprehensive element information.

## 🚀 How to Use / របៀបប្រើប្រាស់

### English

1. **Open the file**: Simply open `index.html` in any modern web browser
2. **Search elements**: Type in the search box using:
   - Element number (e.g., "26")
   - Element symbol (e.g., "Fe")
   - English name (e.g., "Iron")
   - Khmer name (e.g., "ដែក")
3. **View details**: Click on any element card to see detailed information
4. **Switch language**: Click the language toggle button to switch between English and Khmer
5. **Reset search**: Click the "Reset" button to clear your search

### ខ្មែរ

1. **បើកឯកសារ**: គ្រាន់តែបើក `index.html` ក្នុងកម្មវិធីរុករកវែបណាមួយ**
2. **ស្វែងរកធាតុ**: វាយក្នុងប្រអប់ស្វែងរកដោយប្រើ:
   - លេខធាតុ (ឧ. "26")
   - និមិត្តសញ្ញាធាតុ (ឧ. "Fe")
   - ឈ្មោះអង់គ្លេស (ឧ. "Iron")
   - ឈ្មោះខ្មែរ (ឧ. "ដែក")
3. **មើលព័ត៌មានលម្អិត**: ចុចលើកាតធាតុណាមួយដើម្បីមើលព័ត៌មានលម្អិត
4. **ប្តូរភាសា**: ចុចប៊ូតុងប្តូរភាសាដើម្បីប្តូររវាងអង់គ្លេស និងខ្មែរ
5. **កំណត់ឡើងវិញ**: ចុចប៊ូតុង "Reset" ដើម្បីសម្អាតការស្វែងរករបស់អ្នក
